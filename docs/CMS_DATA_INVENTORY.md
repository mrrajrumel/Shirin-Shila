> **System:** Shirin Shila Official Cinematic Portfolio & Editorial CMS

> **Audit Status:** Verified Active Architecture  

---

## 1. Overview & Data Storage Contract

The application operates on a Zero-Database architecture using structured JSON files. All mutable runtime content and user uploads are located in out-of-band persistent storage (`/home/u473489494/shirin_shila_persistent_data/` on Hostinger Linux production), completely decoupled from the Git checkout directories (`versions/<uuid>`).
